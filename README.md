# LeadHub — поиск клиентов через Instagram

WPF-приложение для Windows: пул VPN (VLESS, пинги в мс, слоты с разными IP), пул аккаунтов
Instagram с ротацией нагрузки и лимитами, парсинг бизнес-лидов со всеми фильтрами из скилла
`instagram-whatsapp-lead-parser`, готовые лиды с кликабельными WhatsApp/Telegram-ссылками
и персональным текстом. Отправка — всегда вручную.

## Запуск на Windows (первый раз)

1. Поставь [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (или только Runtime, если берёшь publish-сборку).
2. Склонируй репозиторий:
   ```
   git clone <URL-репозитория> lead-hub
   cd lead-hub
   ```
3. Скачай ядро sing-box (нужен один раз):
   ```
   powershell -ExecutionPolicy Bypass -File tools\fetch-singbox.ps1
   ```
   Скрипт положит `sing-box.exe` в `tools\sing-box\`. Либо скачай вручную с
   [github.com/SagerNet/sing-box/releases](https://github.com/SagerNet/sing-box/releases)
   (файл `sing-box-*-windows-amd64.zip`) и распакуй туда же.
4. Запуск:
   ```
   dotnet run --project LeadHub.App
   ```

## Порядок работы

1. **VPN** — вставь `vless://` ссылки (или URL подписки, как в Happ) → «Импортировать» →
   «Запустить sing-box» → «Проверить пинги». В слотах закрепи узел за каждым слотом —
   каждый слот = отдельный IP (порт `127.0.0.1:108xx`).
2. **Аккаунты Instagram** — импортируй cookies каждого аккаунта (строкой `sessionid=…; csrftoken=…`
   или JSON из расширения EditThisCookie). Cookies шифруются AES-GCM. «Проверить» — лёгкий запрос,
   чтобы убедиться, что сессия жива. Экспорт/импорт `.lhaccount` — перенос пула на другую машину.
3. **Панель парсинга** — выбери ниши (кнопка «Любимые из скилла» — проверенный набор), города-волны,
   режим контактов (по умолчанию WhatsApp-first), фильтры квалификации (пороги уже скилловые:
   <50 000 подписчиков, пост ≤45 дней или сторис ≤48ч, отсев сетей и одиночек), скорость и воркеров.
   Сохрани как пресет. «Запустить прогон».
4. **Прогон** — живой статус по каждому воркеру: текущая пара аккаунт+VPN, запрос, счётчики.
   При 429/challenge Instagram аккаунт автоматически уходит в кулдаун, воркер берёт наименее
   используемую пару и продолжает.
5. **Лиды** — таблица: скопируй текст (ник уже подставлен), открой WhatsApp/Telegram,
   отметь «Написал» **после видимой отправки** (переход по ссылке — не отправка).
   Экспорт CSV (Excel) и HTML-хелпера (тот же интерфейс, что в прошлых прогонах).

## Безопасность аккаунтов (что встроено)

- Ротация выбирает **наименее используемую** пару аккаунт+VPN; счётчик запросов ведётся в БД.
- Дневной кап запросов на аккаунт (по умолчанию 5000) и кулдаун при лимите (120 мин).
- Sticky-страна: аккаунт не прыгает между странами — это триггерит чекпоинты Instagram.
- Пейсинг из скилла: discovery ~1 запрос/2с + джиттер, валидация ≤2 профилей/сек на воркер.
- Дедупликация против всех прошлых лидов + импорт `exclusions.json` из старого пайплайна
  (Настройки → «Выбрать exclusions.json»).

## Данные

- БД и настройки: `%LOCALAPPDATA%\LeadHub\` (`leadhub.db`). Файл `portable.marker` рядом с exe
  переключает в портативный режим (данные рядом с программой).
- Экспорт: `%LOCALAPPDATA%\LeadHub\export\` (или `export\` в портативном режиме).
- Резервная копия БД — кнопкой в Настройках.

## Сборка/публикация

- Собрать release: `dotnet build -c Release`
- Self-contained exe (не требует .NET на машине):
  ```
  dotnet publish LeadHub.App -c Release -r win-x64 --self-contained true -o publish
  ```

## Что НЕ делает приложение

- Никакой автоотправки сообщений: WhatsApp-аккаунты банят за автоматизацию, поэтому приложение
  только готовит лидов и тексты — отправляешь вручную.
- Никакой смены «железа»/HWID для обхода банов: это обход анти-абуза Meta, ведёт к вечным банам
  по устройству и номерам. Безопасная стратегия — ротация аккаунтов в безопасных лимитах.

## Структура

- `LeadHub.Core` — ядро: VPN (vless/подписки/sing-box/Clash API), парсер (матрица ниш × городов,
  квалификация, движок), ротация, SQLite-хранилище, экспорт CSV/HTML. Покрыто тестами (46).
- `LeadHub.App` — WPF-интерфейс (WPF-UI, тёмная тема).
- `LeadHub.Core.Tests` — xUnit-тесты ядра.
